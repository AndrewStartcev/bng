# BNG Elements — WordPress theme

Кастомная двухъязычная тема без визуального конструктора. По мотивам клиентских RU/EN standalone HTML. Оригинальные тексты, продуктовая линейка, марки, характеристики и новости извлечены в \`data/source-content.json\`. Это **исходные данные**, а не автоматически сгенерированный текст.

## Что сделано
- Разделы: Home, Products, Rock, Flowsheet, Evidence, Milestones, News, Company (RU + EN).
- Шаблоны PHP по каждому разделу в \`template-parts/sections/\`; данные сервером выводятся в HTML, сайт работает без JS-фреймворка.
- Переключение RU/EN и отдельные URL \`/\`, \`/en/\`, \`/ru/products/\`, \`/en/products/\` и т. п.
- CPT \`bng_section\` без архива и REST-публикации, при активации создаются семь разделов на язык.
- Главная — ACF поля заголовка RU/EN, видео, постера; текст и H1 внутренних разделов тоже редактируются через ACF.
- Таблица 10 продуктов, фильтры по назначению, параметры и спецификации марок. PDF привязываются по коду марки в редакторе продуктов; несуществующие ссылки не публикуются.
- Фото галерея, документы, Options с логотипом/почтой.
- Мобильная навигация, адаптивные сетки, семантика, canonical/hreflang, интеграция с Rank Math.

## Подключение к WordPress
1. Разместить **только тему** в \`wp-content/themes/bng/\`.
2. Установить **ACF Pro** (нужен Pro для Gallery, Repeater, Options). Rank Math SEO — рекомендуемый SEO-плагин. WordPress ядро, PHP и ACF должны быть совместимых поддерживаемых версий.
3. В \`Настройки → Чтение\` назначить существующую статическую страницу «Главная».
4. Активировать тему. Если тема уже активна, после обновления файлов **один раз** пересоздать/проверить отсутствующие разделы: см. ниже WP-CLI.
5. В \`Настройки → Постоянные ссылки\` нажать «Сохранить» для обновления правил маршрутизации.
6. Для RU/EN проверить \`/\`, \`/en/\`, \`/ru/products/\`, \`/en/products/\` и переключение языка.
7. В ACF на главной установить готовое, обрезанное видео и постер. Видео, пришедшее от клиента, по ТЗ обрезать: первые 6 и последние 8 секунд.
8. На странице «Порода» загрузить 3 фотографии в точном клиентском порядке. На странице «Продукты» прикрепить PDF по кодам марок (например \`PS-K01.A\`), когда документы будут получены.

### Если тема уже была активирована до обновления файлов
Выполнить через WP-CLI из корня установленного WordPress:
\`\`\`bash
wp eval 'bng_seed_sections();'
wp rewrite flush
\`\`\`

### Важное про исходники
\`resourse/\` исключена из последнего Git-дерева и в \`.gitignore\`; клиентские HTML и видео остались **в старых коммитах**, но не загружаются при клонировании \`--depth=1\`. Для сервера:
\`\`\`bash
git clone --depth=1 --single-branch --branch=main https://github.com/AndrewStartcev/bng.git .
\`\`\`

### Ограничения текущего этапа
- Фото из отдельного письма и PDF спецификации не получены. Документы намеренно не связываются с архивными DOCX из упакованного HTML.
- Видео на server не загружено, нужна обработка MP4 и загрузка в медиабиблиотеку.
- Нужна финальная визуальная сверка с исходной вёрсткой на реальном dev-домене, особенно карты и технологической схемы. Здесь реализована серверная независимая HTML/CSS-версия.
- Активация ACF Pro и Rank Math на реальном WordPress требует доступа к админке / SSH; тема их не устанавливает автоматически.
