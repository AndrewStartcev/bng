# BNG Elements — кастомная WordPress-тема

Клиентские исходники (`resourse/`: RU/EN standalone HTML, MP4 и требования) исключены из текущей версии Git и добавлены в `.gitignore`, чтобы не попадать на сервер. Оригиналы можно найти в истории репозитория до коммита исключения или хранить отдельно локально. Для нового развёртывания рекомендуется `git clone --depth=1`, чтобы не скачивать тяжёлые файлы из старых коммитов.

Это первая рабочая версия каркаса, **не финальный перенос макета/контента**.

## Установка
1. Разместить файлы темы в `wp-content/themes/bng/`.
2. Установить/активировать ACF Pro для Options, Gallery и Repeater.
3. Создать обычную страницу «Главная» и назначить её статической главной в «Настройки → Чтение».
4. Активировать тему: при активации создаются семь внутренних разделов на каждом языке.
5. Открыть «Настройки → Постоянные ссылки» и сохранить настройки для обновления rewrite rules.
6. Заполнить ACF у главной и у разделов. Оригинальные тексты и изображения ещё требуют извлечения из клиентских HTML.

## Роутинг
- `/` — главная RU
- `/en/` — главная EN
- `/ru/rock/`, `/en/rock/` и аналогично для evidence, flowsheet, products, milestones, news, company.

Реализовано 8 разделов на язык (главная плюс 7 внутренних). CPT `bng_section` имеет публичные страницы, но не имеет архива и API для создания через REST.

## Следующая итерация
Извлечь разметку, COPY RU/EN и упакованные изображения/шрифты из клиентских standalone HTML, перенести блоки в PHP, заполнить посты. Проверить роутинг, мобильный интерфейс и видео на dev-сервере. Исходный 81MB `video.mp4` не использовать напрямую: требуется обрезать первые 6 и последние 8 секунд, сжать и загрузить в медиабиблиотеку.

## Архитектура
Лёгкая PHP-тема без сборщика JS, без Elementor. Основа: `inc/`, ACF, WordPress CPT, семантический HTML, CSS/JS в `assets/`.
