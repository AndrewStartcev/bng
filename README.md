# BNG — WordPress, один публичный адрес

Тема сохраняет оригинальные тексты из RU/EN standalone в `data/source-content.json`. Стили, локальные шрифты, логотип и шаблоны разделов вынесены в `assets/` и `template-parts/sections/`. Исходные HTML/видео исключены из актуальной версии Git через `.gitignore`; они остаются в старой истории.

## Устройство
- **Один URL**: `/`. Восемь экранов и два языка уже находятся в HTML; переключение — JS без перезагрузки и без изменения URL.
- **Админка**: главная — стандартная статическая страница; семь внутренних экранов — CPT `bng_section`, без публичных URL. Сохраняются ранее созданные RU/EN записи: в качестве основной используется запись `*-ru`, записи `*-en` не удаляются и скрываются из общего списка.
- **ACF Pro**: два независимых метабокса — «Контент — Русский» и «Content — English». У каждой страницы собственные блоки с вертикальными вкладками; короткие поля в несколько колонок, длинные в textarea, списки в repeater, дополнительный текст в визуальном редакторе.
- **Источник начального контента**: `data/source-content.json`. При отсутствии сохранённых ACF-полей используется оригинал. Для повторителей в ещё не заполненных записях подгружаются исходные строки.
- **Медиа**: на главной отдельные поля видео и постера для каждого языка; «Порода» — галерея; «Продукты» — PDF-спецификации по коду марки.
- **SEO**: один canonical на главную. Без фиктивных hreflang для экранов, у которых нет собственных URL.

## Развёртывание
1. Обновить тему в `wp-content/themes/bng/` из `main`.
2. Установить и активировать ACF Pro; Rank Math при необходимости. Тема их не скачивает автоматически.
3. В «Настройки → Чтение» назначить статическую главную страницу.
4. Из корня WordPress выполнить `wp eval 'bng_seed_sections();'` и `wp rewrite flush` (если тема была активна до обновления).
5. Проверить `/` и переключение восьми экранов, RU/EN, кнопки, мобильное меню, таблицы продуктов и поля редактора.

## Ожидаемые клиентские файлы
- Обрезанное видео: убрать первые 6 секунд и последние 8 секунд, загрузить в медиабиблиотеку.
- Три фото «Порода» в нужном порядке.
- PDF продуктовых спецификаций — по мере получения.

## Ограничения
Проверка PHP-синтаксиса выполняется GitHub Actions, визуальное сравнение с оригиналом необходимо провести на dev-сайте. Перенесённые блоки используют существующие CSS-шаблоны, не являются дословной копией исходной упакованной JavaScript-реализации. Вся детальная продуктовая номенклатура, параметры и химические формулы пока берутся из оригинального JSON без интерфейса редактирования каждой марки.
