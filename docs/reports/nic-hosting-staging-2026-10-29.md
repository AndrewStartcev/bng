# BNG: восстановление на хостинге клиента, 29.10.2026

## Выполнено

- Создан основной сайт bng-elements.ru с PHP 8.3.
- bng-elements.com, www.bng-elements.com и www.bng-elements.ru привязаны как синонимы к той же папке сайта. Вторая установка WordPress не создавалась.
- Загружены и распакованы полные файлы dev-сайта после обновления видео и доменного переключения.
- В wp-config.php указаны реквизиты новой базы и подключён bng-domain-config.php до wp-settings.php. Конфиденциальная конфигурация и архивы в репозиторий не включаются.
- База предварительно восстановлена локально в MySQL 8.0. WP-CLI search-replace с поддержкой сериализации заменил семь вхождений HTTP dev-адреса на https://bng-elements.ru, GUID исключены. Для HTTPS dev-адреса в базе совпадений не было.
- Результирующий SQL импортирован в пустую клиентскую базу: 16 таблиц, phpMyAdmin подтвердил успешное выполнение 174 запросов. Пользователи и ACF сохранены.
- Стандартная заглушка index.html переименована в nic-placeholder.html.disabled, сохранена для обратимости.
- Установочный архив размещён вне публичной папки docs.

## Проверка нового сервера до DNS

HTTP-запросы непосредственно на IP нового хостинга с Host каждого домена:

| Проверка | Результат |
|---|---|
| bng-elements.ru | HTTP 200; начальный язык ru; html lang=ru |
| bng-elements.com | HTTP 200; начальный язык en; html lang=en |
| Доменный переключатель | корректные URL обоих доменов в мосте данных |
| Новое видео на обоих доменах | HTTP 200; 78 715 784 байта |
| Параметры видео | autoplay, loop, muted, playsinline |
| Скрипт видео | содержимое совпадает с подготовленной темой |
| PDF PS-K04.C | HTTP 200; корректная сигнатура PDF |
| Старые dev-адреса в HTML | 0 на обоих доменах |

Это проверка приложения на новом сервере, а не проверка публичного HTTPS после переключения DNS. В браузере на dev до переноса отдельно проверены восемь разделов RU/EN, воспроизведение видео без клика, повторный запуск после возвращения на главную и мобильная ширина 390 px.

## Что отложено

Пользователь попросил пока пропустить SSL. Письма со ссылками на приватные ключи не запрашивались, ключи не извлекались. В договоре уже есть сертификаты GlobalSign SSL DV для обоих доменов, действующие до 03.04.2027. Сертификат .ru проверен: SAN включает bare и www.

DNS не переключался, почтовые записи не менялись. Перед публичным запуском:

1. Получить приватные ключи существующих сертификатов и установить SSL на оба домена с www.
2. Проверить HTTPS, SNI, цепочки сертификатов и редиректы без отключения проверки сертификата.
3. Переключить только необходимые DNS-записи сайта, сохранив MX/TXT.
4. Повторить полную проверку восьми разделов RU/EN, переключателя доменов, PDF, видео и входа редактора.
5. Убедиться, что не было новых правок на dev после экспорта; при наличии перенести свежие данные перед запуском.

Изменение пароля MySQL необходимо одновременно отражать в wp-config.php. До завершения SSL/DNS публичный перенос не считается завершённым.
